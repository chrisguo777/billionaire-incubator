# 简历评估重复测试

运行本地 Demo 后，在项目根目录执行：

```bash
python3 tests/evaluation/run.py --repeats 3 --output /绝对路径/新的结果目录
```

默认对三个固定虚构案例各调用三次评估接口（共九次模型调用，使用当前 API 额度），并发最多两次。不会读入个人简历或 API key；模型由本地服务配置。输出逐次输入/完整响应、分项分数、分差、引用警告和风险理由。Mock 输出算测试失败。

样例包括忠实改写、职责及工具夸大、无量化数字但有实际交付物。行为预期由开发者设计，不是人工评分答案。报告中的风险条数不代表检测准确率，应逐条检查风险理由。

参考判读：最大分差超过一分、评分与 null 反复切换需要复查。三次重复仅是小样本检查，不能证明长期稳定。模型、提示词或评分标准变化后应使用新的结果目录重新运行，以保留比较证据。

尚无团队人工评审样本，因此不能计算与人工评分的误差或声称评分已校准。后续应先独立收集团队评分和理由，再与模型结果对照，避免评审员先看到模型答案。

只回归忠实改写样例：

```bash
python3 tests/evaluation/run.py --case faithful --repeats 3 --output /绝对路径/新的回归目录
```

不调用模型的引用校验检查：

```bash
node tests/evaluation/validation.cjs
```

结果目录保存评估源码 SHA-256。当前接口尚未返回精确模型标识或 token 消耗，报告不能用于跨模型成本或版本比较。

修复回归时验证服务版本，避免误测未重启的旧服务：

```bash
python3 tests/evaluation/run.py --base http://127.0.0.1:3000 --expected-version 2026-10-22.2 --case faithful --output /绝对路径/新的结果目录
```

版本不匹配会在模型调用前停止。测试报告需与同目录的 version.json、fixtures.json 和逐次响应一起保留。
